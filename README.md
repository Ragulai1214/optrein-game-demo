# HEART BOX — SYSTEM PROTOTYPE 0.3.0

2026年11月15日の改訂と個別指定を反映した検証版です。`index.html`をブラウザで開くだけでプレイできます。外部ライブラリ、通信、インストールは不要です。

## 進行

- 第1ラウンド：双方HP3、1フェーズ3〜4ターン、アイテム・GM能力なし。
- 第2ラウンド：プレイヤーHP3／GM HP4、1フェーズ5〜8ターン。アイテム・GM能力を解禁。
- 長さは均等抽選。H数は3ターンなら1個固定、4ターンなら2個固定、5ターンなら2／3個を各50%、6ターンなら2／3／4個を各1/3、7ターンなら3／4個を各50%で抽選し、配置をシャッフル。8ターンは従来どおり4個固定です。今回の変更はH数のみで、ラウンドごとのターン数範囲は変更していません。
- H総数・残りH数はフェーズ開始から5秒間だけ表示。ログに総数は残しません。
- GMが1フェーズ内で累計2ダメージを受けるとフェーズ終了。通常ボムなら2回、強化ボムなら1回です。通常ボムの後に強化ボムが命中した場合は残り1ダメージだけ与え、フェーズ上限2を超えません。GMが途中で回復しても累計被ダメージは減りません。未実行ターンは飛ばします。結果確認後「次フェーズへ」で進みます。
- 命中しなかった場合も全ターン終了で次フェーズへ進みます。
- 第1ラウンド勝利後に初めて次ラウンドを案内。HP・アイテムCD・封鎖・シールド修復・ボム強化・能力・取得情報を初期化します。通算ログと戦績、ユーザーのシールド設定は維持します。
- 第2ラウンド勝利またはいずれかのラウンドでプレイヤーHP0なら対戦終了です。

## 行動

待機はHで自分に1ダメージ、Eで何も起きません。シールドは防御し、使用後に修復します。クールタイムは画面で0〜3ターンに変更可能（初期値1）。0なら連続使用可能です。変更は次回使用から適用し、進行中の修復には影響しません。設定はリスタートで維持、ページ再読み込みで初期値に戻ります。

通常ボムは命中・自爆とも1ダメージ。自爆で強化状態となり、命中・自爆とも2ダメージになります。連続失敗しても2を超えません。シールド・アイテム使用では維持し、待機・ボム成功で解除します。フェーズ境界だけでは解除しません。

## 常設アイテムとCD

第2ラウンド開始時から4種類を1つずつ使用できます。配布・消費・所持スロット抽選はありません。異なる使用可能アイテムを同じターンに使うことはできます。

| 種類 | 効果 | CD |
|---|---|---|
| レントゲン | 現在のH/Eを確認 | 2フェーズ |
| ソナー | ランダムな連続2ターンにHがあるかだけ確認 | 1フェーズ |
| 緊急修復キット | シールド修復を即解除 | 3ターン |
| 回復アンプル | HPを1回復、最大3 | 3フェーズ |

全アイテムのCDは使用したフェーズの次から指定フェーズ数だけ使用不可です。例：P1でレントゲン使用→P2〜P3使用不可→P4再使用可能。ソナーはP1使用→P2使用不可→P3再使用可能。使用したフェーズ内も再使用不可で、ターン進行ではCDは減りません。強奪の封鎖は従来どおり2ターンです。

回復アンプルは使用したフェーズの次から3フェーズ使用不可です。例：P1で使用→P2〜P4使用不可→P5再使用可能。使用したP1でも再使用はできません。フェーズの早期終了も1フェーズとして数えます。

ソナーは現在を含む未実行の連続2ターンを均等抽選します。表示例：`T4:T5 あり`。HH・HE・EHはいずれも「あり」、EEだけ「なし」。残り1ターンならそのターンのみ。満タンでの回復、修復不要時のキットは使用できずCDも発生しません。

## GM能力

能力権はフェーズごとに独立抽選。回復60%、暗黒80%、強奪30%です。

- 暗黒：毎ターン条件成立時50%で発動し、現在と次ターンの情報アイテム使用を禁止。1フェーズ1回、フェーズ終了で解除。
- 回復：HPが最大未満なら1回復。1フェーズ1回。
- 強奪：使用権があればフェーズ開始時に1回判定。CD・既存封鎖のないアイテムからランダムに1つ選び、現在を含む2実行ターン使用不能にします。追加の50%発動抽選は廃止。対象なしなら不発、後続ターンでは再試行しません。

強奪ではアイテムは消滅せず、元のCDも変更しません。封鎖はフェーズをまたいでも残り実行ターン分維持します。対象はCDが完了しているかで判定し、HP満タンや修復不要でも候補になります。暗黒による妨害も候補からの除外条件にはしません。これは常設CD制の検証用解釈です。重み付きの旧強奪AIは廃止しました。

## デバッグ・戦績

デバッグで内部配置、能力判定、CD期限、強奪候補と均等確率を表示します。HP、未公開の配置、使用権を変更し、個別アイテムのCD・封鎖を解除できます。変更は行動選択前のみで、GM能力は再処理しません。配置変更時は取得情報を消去します。双方HP0への変更はプレイヤー敗北です。

設定変更・デバッグ書き換えをした対戦は累計対象外。デバッグ表示だけなら対象です。通常対戦の勝敗と平均実行ターン数をlocalStorageに保存します。新ルール用の保存キーを使い、旧戦績と混在させません。第1ラウンド勝利のみでは累計を加算しません。

## ファイル・検証

- `script.js`：ゲームエンジン、CONFIG、UI描画
- `index.html` / `style.css`：画面
- `test.js`：ルールと画面描画の回帰テスト（`node --test test.js`）

`HeartBox`に乱数と時計の関数を渡せるため、抽選と5秒表示を検証できます。テストは実ブラウザの視覚確認を代替するものではありません。

暫定値：第1ラウンドHP、ターン数の抽選、情報アイテム・修復のCD、CDの数え方と持ち越し、ボム成功時解除。世界観、RV-21、ライブラリー演出は未実装です。

第1ラウンドの最初のフェーズは必ず3ターン・H1個です。リスタート時も適用され、第2フェーズ以降は従来の抽選に戻ります。
